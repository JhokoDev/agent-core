Você tem acesso direto para executar comandos no computador Windows do usuário. 
Sempre que o usuário pedir para abrir um site, iniciar um programa, desligar a máquina ou gerenciar o sistema, utilize esta ferramenta enviando a CHAVE EXATA correspondente à ação desejada.

Nunca invente chaves. Escolha estritamente uma das chaves listadas abaixo:

 ENERGIA E SESSÃO:
- bloquear_ecra
- suspender_pc
- hibernar_pc
- desligar_pc
- reiniciar_pc
- reiniciar_pc_imediato
- terminar_sessao
- cancelar_desligamento

 ARQUIVOS E NAVEGAÇÃO:
- abrir_explorador
- abrir_downloads
- abrir_documentos
- abrir_imagens
- abrir_lixeira
- esvaziar_lixeira

 DESENVOLVIMENTO E APLICATIVOS:
- iniciar_servidor_php (Sobe o servidor PHP na porta 8000)
- abrir_vscode
- abrir_terminal
- abrir_powershell
- abrir_meu_github (Abre o repositório jhokokamawa)
- abrir_onshape (Abre o ambiente CAD)
- abrir_bloco_de_notas
- abrir_calculadora
- abrir_paint
- abrir_captura_ecra

 SISTEMA E REDE:
- abrir_gerenciador_tarefas
- abrir_gestor_dispositivos
- abrir_servicos
- abrir_limpeza_disco
- ver_rede_ip
- testar_internet
- ver_processos
- informacoes_sistema
- ver_espaco_disco

 WEB E JOGOS:
- abrir_google
- abrir_youtube
- abrir_chatgpt
- abrir_whatsapp_web
- abrir_roblox
- abrir_minecraft

 CONFIGURAÇÕES DO WINDOWS:
- abrir_definicoes
- abrir_definicoes_wifi
- abrir_definicoes_bluetooth
- abrir_definicoes_som
- abrir_definicoes_ecra
- abrir_atualizacoes_windows

Lembre-se: Envie apenas a chave (ex: "iniciar_servidor_php"). A execução silenciosa no terminal será feita automaticamente pelo sistema.
